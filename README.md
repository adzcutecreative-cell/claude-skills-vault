# KIACreative — Claude AI Skills Vault

Landing page for the **1,500 Ready-to-Install Claude Skills for Etsy & Small Business** digital product by KIACreative.

**Live site:** https://adzcutecreative-cell.github.io/kiacreative-ai-skills-vault/

## What's inside

A single-page vault where buyers can browse skill categories, preview skill instructions, copy them, and download ready-to-install `.md` files for Claude.

## Product details

- 1,500 skills across multiple small-business categories
- Etsy listing optimization, product descriptions, SEO, customer service, marketing
- Copy-paste and download support
- Commercial use friendly

## Tech

- Static HTML + Tailwind CSS (CDN) + Lucide icons (CDN)
- No build step, hosted on GitHub Pages

## Deploy

Any static host works. GitHub Pages serves `index.html` directly from the `main` branch root.
