How to Install & Use Claude Skills in 3 Minutes

Works on free and paid Claude plans—zero coding required.

1

Personalize Your Brand Context (Optional)

Click My Brand in the top bar and enter your shop name, target audience, and tone. Every skill in the vault will automatically embed your details.

2

Copy or Download Any Skill

Open any skill card and click Download .md (or 1-Click Copy) to grab the clean YAML + Markdown skill file.

3

Add to Claude Settings

Open Claude → Settings → Capabilities / Skills (make sure Code Execution & File Creation is enabled), upload the .md file or paste the instructions into a Project/Skill. From then on, simply mention the skill name in any new chat!
